# bbb — portfolio

Личное портфолио: **кодер · пентестер · full-stack · сетевик**. Тёмный «денежный» стиль, глассморфизм, WebGL-сцены и 3D-переходы между экранами, звук под трек и гараж с **BMW M4 CSL**.

## Что внутри

- **Прелоадер**: терминальный бут-лог, золотой логотип, реальный прогресс загрузки (шрифты, текстуры, трек, 3D-модель, шейдеры). В конце предлагает войти со звуком или без.
- **Звук «из-под воды»**: трек сначала играет через low-pass, хорус и реверб, как под водой. По мере скролла фильтр открывается, и на первом экране он звучит уже в полную силу. Вспышка в момент «всплытия».
- **Горящие баксы**: инстансированные купюры ($100 и $2 из твоих фото) летают вокруг и сгорают по мере скролла: шейдерный огонь, обугливание, искры, частицы углей. В контактах они «восстанавливаются». Клик по купюре поджигает её, счётчик `$ burned` внизу.
- **WebGL-переходы между сценами**: огненный прожиг (деньги → VPN, гараж → контакты) и цифровой глитч (VPN → гараж). Сверху bloom, лёгкая хроматическая аберрация и виньетка.
- **3D-переходы секций**: пиннинг, rotateX/translateZ, 3D-карусель ролей, coverflow проектов, анимации из букв.
- **Obscure VPN** ([obscurelegal.shop](https://obscurelegal.shop), бот [@vpnobscure_bot](https://t.me/vpnobscure_bot)): полёт через шестигранный «зашифрованный» туннель, потом глобус с нодами и дугами, печатающийся терминал и пинги нод.
- **Гараж**: BMW M4 CSL (Black Sapphire по умолчанию), студия с шестигранным светом и отражающим полом. Кнопка **ENGINE START/STOP** и **газ** (кнопка или пробел): синтез рядной «шестёрки» S58 на AudioWorklet со стартером, турбосвистом, отсечкой и хлопками на сбросе (с огнём из выхлопа), тахометр, смена цвета кузова, вращение мышью.
- **Пасхалки**: терминал (<kbd>`</kbd> или кнопка внизу, `help`), Konami code ↑↑↓↓←→←→BA (денежный дождь), <kbd>m</kbd> включает и выключает звук.
- Кастомный курсор, магнитные кнопки, tilt-карточки, меню с переходом-шторкой, HUD (секция, прогресс, время, fps).
- Адаптивность: облегчённые сцены и lite-модель машины на телефонах, адаптивное разрешение рендера при просадке fps, `prefers-reduced-motion`.

Шрифты: **Unbounded** (заголовки), **Cormorant Garamond** (курсивные акценты), **JetBrains Mono** (системный/код), **Manrope** (текст).

## Запуск локально

Нужен любой статический сервер (ES-модули и AudioWorklet не работают с `file://`):

```bash
npx http-server -c-1 .
# или
python3 -m http.server 8080
```

Открыть `http://localhost:8080`. Сборка не нужна: библиотеки лежат в `vendor/` (three.js r186, GSAP 3 + ScrollTrigger, Lenis).

Полезные параметры URL:
- `?dpr=2`: зафиксировать разрешение рендера (без адаптивного снижения).
- `?car=m5`: вместо модели показать процедурную M5 F90 (запасной вариант, если модели нет).

## Деплой на GitHub Pages

Settings → Pages → *Deploy from a branch* → ветка `main`, папка `/ (root)`. Всё статическое, ничего собирать не нужно.

> Загруженные исходники моделей в корне репозитория (`2021_bmw_m4_competition.glb`, `2025_bmw_m4_gt3_evo_g82.glb`, `bmw_m4csl.zip`, всего ~47 МБ) сайтом не используются: оптимизированная CSL лежит в `assets/models/`. Исходники можно удалить, чтобы репозиторий и Pages были легче.

## Как поменять контент

| Что | Где |
| --- | --- |
| Тексты, роли, проекты, контакты, цифры в «Кто я» | `index.html` |
| Машина: модель, характеристики, цвета, точки выхлопа и фар | `js/car-config.js` |
| Цвета кузова (палитра) | `PAINTS` в `js/gl/m5.js` |
| Трек | `assets/audio/addiction.mp3` (замени файл с тем же именем) |
| Купюры и портрет | `assets/img/bills.jpg`, `assets/img/franklin.jpg` |
| Цвета, шрифты, глассморфизм | `css/main.css` (переменные в `:root`) |

Telegram — @barbqwe. Email (`hello@bbb.dev`), GitHub, цифры в статистике и описания проектов — **заглушки**, замени на свои.

Другая модель машины: положи `.glb` в `assets/models/` и опиши её в `js/car-config.js` (имена материалов краски, фар и стопов можно посмотреть через `npx @gltf-transform/cli inspect model.glb`). Большие модели лучше сжать:

```bash
npx @gltf-transform/cli optimize in.glb out.glb --compress meshopt --texture-compress webp --texture-size 2048 --palette false
```

## Структура

```
index.html            разметка и весь контент
css/main.css          стили
js/main.js            прелоадер, скролл, анимации, HUD, меню, гараж-UI
js/car-config.js      пресеты машины
js/gl/stage.js        рендерер, смешивание сцен (огонь/глитч), bloom, финальный грейд
js/gl/money.js        горящие купюры, угли, золотая пыль
js/gl/tunnel.js       VPN-туннель и глобус
js/gl/garage.js       студия, пол, свет, фары, огонь из выхлопа
js/gl/glbcar.js       загрузка и нормализация GLB-модели
js/gl/m5.js           процедурная M5 F90 (fallback) + палитра
js/audio/hub.js       аудиограф: «подводный» фильтр, анализатор, sfx
js/audio/v8.js        физика оборотов, старт/стоп, турбо
js/audio/v8-worklet.js синтез мотора (V8 / I6)
js/ui/*               курсор, эффекты текста, терминал
vendor/               three.js, GSAP, Lenis
```
